# Contributing to IconSprout

Thank you for considering contributing to **IconSprout**! 🎉

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your feature or fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Commit your changes** with a clear message:
   ```bash
   git commit -m "feat: add your feature description"
   ```
4. **Push** to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
5. **Open a Pull Request** against the `main` branch

## Guidelines

- Keep changes focused and minimal — one feature per PR
- Update the README if you add new features or change usage
- Follow existing code style and conventions
- Write clear commit messages (use conventional commits: `feat:`, `fix:`, `docs:`)

## Reporting Issues

Found a bug or have a feature request? [Open an issue](https://github.com/wiradifit/iconsprout/issues/new) with:
- A clear description of the problem or request
- Steps to reproduce (for bugs)
- Expected vs actual behavior
