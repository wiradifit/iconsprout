# IconSprout

> Generate a complete favicon bundle — PNGs, Apple touch icons, Android masks, and ICO files — from a single uploaded logo or entered emoji text in seconds.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![GitHub Stars](https://img.shields.io/github/stars/wiradifit/iconsprout?style=social)](https://github.com/wiradifit/iconsprout)

## ✨ Features

- **Upload or type** — Upload your own logo image or simply type an emoji to get started instantly
- **Smart color detection** — Automatic background color extraction and intelligent contrast adjustment for legible icons at any size
- **Full favicon bundle** — Generates every standard size: 16×16, 32×32, 48×48, 64×64, 180×180, 192×192, 512×512, plus a bundled `.ico` file
- **Apple & Android support** — Produces Apple touch icons (rounded), Android maskable icons, and proper `mask-icon` variants
- **One-click ZIP download** — Packages everything into a ready-to-deploy `favicon-pack.zip`
- **HTML snippet generator** — Outputs a copy-paste-ready HTML block with all `<link>` and `<meta>` tags for browsers, iOS, and Android
- **Client-side only** — No server required; everything runs in the browser via the Canvas API, keeping your images private

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/wiradifit/iconsprout.git
cd iconsprout

# Open index.html directly in your browser
open index.html

# Or serve via a local server (recommended for best performance)
npx serve .
# or
python -m http.server 8000
```

Open `http://localhost:8000` (or your chosen port) in a modern browser. No build step, no dependencies to install — just open and go.

## 📖 Usage & Examples

### Basic Workflow

1. **Choose your source** — Click **"Upload Logo"** to select an image file, or type/paste an emoji into the input field.
2. **Pick a background** — Optionally set a solid background color. The app can auto-detect the dominant color from your image.
3. **Generate** — Hit **"Generate Icons"** and watch as every variant is produced in real time on canvas elements.
4. **Preview** — A live grid shows all generated icons at their respective sizes.
5. **Copy HTML** — Switch to the **"HTML Snippet"** tab to copy the ready-to-paste `<head>` block.
6. **Download** — Click **"Download ZIP"** to save the complete icon pack to your machine.

### Example: Emoji-Based Favicon

```
Input: "🌱"
Background: Auto-detected (#2d6a4f)
Result: Full favicon bundle with green-tinted leaf icon at every size
```

### Example: Custom Logo Upload

```
Upload: company-logo.png
Background: Transparent (auto-detected) + solid fallback (#ffffff)
Result: All formats generated; ICO contains multiple resolutions
```

### Generated Sizes

| Size | Format | Purpose |
|------|--------|---------|
| 16 × 16 | PNG | Browser tab favicon |
| 32 × 32 | PNG | Browser tab (HiDPI) |
| 48 × 48 | PNG | Legacy fallback |
| 64 × 64 | PNG | Windows tile |
| 180 × 180 | PNG | Apple touch icon |
| 192 × 192 | PNG | Android home screen |
| 512 × 512 | PNG | Android Play Store / splash |
| — | ICO | Multi-resolution Windows icon |

### HTML Snippet Output

```html
<!-- Favicon Bundle — Generated by IconSprout -->
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="48x48" href="/favicon-48x48.png">
<link rel="icon" type="image/png" sizes="64x64" href="/favicon-64x64.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="icon" type="image/ico" href="/favicon.ico">
<meta name="theme-color" content="#2d6a4f">
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#2d6a4f">
```

## 🏗️ Tech Stack

| Component | Technology |
|-----------|------------|
| Language | HTML5, CSS3, Vanilla JavaScript (ES6+) |
| Canvas API | Client-side icon rasterization and format conversion |
| ZIP creation | `JSZip` (bundled via CDN) |
| File handling | Native File System APIs (`<input>`, `Blob`, `URL.createObjectURL`) |
| Styling | Pure CSS — custom properties, Flexbox, CSS Grid |
| No build toolchain | Runs entirely in-browser; zero dependencies to install |
